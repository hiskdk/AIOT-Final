## 設計說明（DESIGN.md 第 7 章）

- **rules.yaml**：所有數值門檻（金額、年限）寫成 YAML 規則檔，由 Guardrail 以確定性程式讀取；**LLM 不參與判定**，只解釋結果。各校細節不同，上線前須與校方財產組核對並替換數值。
- **RAG 知識庫**：法規文件切塊後建 BM25 + 向量索引（見 `tools/rag.py`）；每個建議必須附引用條文來源。
- **std_class_table.csv**：來源為行政院主計總處《財物標準分類》[14]，提供最低使用年限 `L`，供 M3 殘值計算與 M4 報廢檢核使用。
