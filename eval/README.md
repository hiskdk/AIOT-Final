# eval — 評估模組

> **狀態：Proposal 階段，評估任務設計中，尚未實作。**

本資料夾包含 LabSteward 的評估框架（DESIGN.md 第 11 章）：

| 檔案 | 功能 | 狀態 |
|------|------|------|
| `tasks.jsonl` | 情境任務與標準答案（約 50 題） | ☐ Planned |
| `run_eval.py` | 評估腳本 | ☐ Planned |
| `metrics.py` | 指標計算 | ☐ Planned |

## 實驗設計（DESIGN.md 第 11.1 章）

**Dataset**：
- 本實驗室財產清冊（去識別化）
- 合成財產與借用紀錄
- 二手市場掛牌資料（筆電、螢幕、GPU、量測儀器）
- 約 50 題情境任務（管理 25 題、採購 25 題），人工標註正確答案與應引用法規

**Baselines**：
- B1：人工 Excel 流程
- B2：單一 LLM 端到端（無工具）
- B3：純 RAG 問答（有法規、無工具）

## 評估指標（DESIGN.md 第 11.2 章）

| 指標 | 說明 |
|------|------|
| 任務成功率 | 最終輸出符合標註答案的比例 |
| pass^4 | 同一任務重跑 4 次皆成功的比例（穩定度） |
| 欄位抽取 F1 | M1 從發票抽取欄位的 F1 |
| 殘值 MAPE | 市場價值預測的平均絕對百分比誤差 |
| 法規違規率 | 輸出違反 rules.yaml 的情境比例 |
| 錯誤放行率 | 應被攔截卻被放行的比例 |
| 證據正確性 | 引用條文是否正確支持結論 |
| 作業時間 | 輸入到產出文件的平均時間 |
